FAQ

Deluxe Saloon

Can I search any Hindi song?
Yes. The Search button sends your search directly to YouTube. No YouTube API key is required.
Why doesn't the song play inside this page?
YouTube does not provide its search results to a normal static webpage without its API. This version therefore opens the official YouTube search page instead of pretending to provide a search system that will stop working.
Does this require a server?
No. Everything in this page is HTML, CSS and JavaScript and can be hosted directly on GitHub Pages.
Can I add my own music categories?
Yes. The category buttons are simple YouTube search queries and can be changed inside this file.
