FAQ

Deluxe Saloon, Explained

What is Deluxe Saloon?
A browser-based Hindi music and neighbourhood-saloon experience.
Is it free?
Yes. This version is designed to work on GitHub Pages.
What music is included?
The built-in library includes Hindi classics, 90s, 2000s, Bollywood favourites, romantic songs and contemporary tracks.
Why does search open YouTube?
A static GitHub Pages site cannot retrieve YouTube's search results into its own page without the YouTube Data API or a backend. This version therefore uses YouTube's own search page and needs no API key.
Does this website download music?
No. The website does not download or host copyrighted audio. It sends the selected search to YouTube.
