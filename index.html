FAQ

Deluxe Saloon

Can I search any Hindi song?
Yes. With the YouTube Data API configured, the search box can query YouTube dynamically rather than relying on a fixed list of songs.
Does this website host the music?
No. Selected songs are played using YouTube's embedded player technology. Your website does not download or host the music files.
Can I use this on GitHub Pages?
Yes. The interface is completely static and can be deployed on GitHub Pages. The YouTube API key should be restricted to your GitHub Pages domain.
Can I make my own categories?
Yes. The category buttons near the search box are simply predefined YouTube searches and can be changed to anything you want.
